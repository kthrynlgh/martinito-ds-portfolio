# Glossary

Terms I've defined once here so I can reference them from any notebook.

:::{glossary}
epoch
: One full pass of the training algorithm over the entire training dataset.

batch size
: The number of samples processed before the model's weights are updated.

learning rate
: The step size used when updating weights during gradient descent.

overfitting
: When a model performs well on training data but poorly on unseen data because it has memorized noise rather than learned structure.

activation function
: A nonlinearity applied to a neuron's output, such as ReLU, sigmoid, or tanh, that lets a network model nonlinear relationships.

backpropagation
: The algorithm that computes gradients of the loss with respect to each weight by applying the chain rule backwards through the network.
:::
