# Lab Activities

Shorter, hands-on exercises completed during lab sessions. These are more experimental than the assignments; the goal is to try a technique and watch how it behaves.

| # | Title | Topic | Description |
|---|-------|-------|----------------|
| 01 | [*Neural Network Forward Propagation and Loss Evaluation*](./lab-exercise-01.ipynb) | *Forward Propagation* | Computes a single forward pass and squared error using custom weights and ReLU. |
| 02 | [*Implementing Forward and Backward Propagation*](./lab-exercise-02.ipynb) | *Forward and Backward Propagation* | Executes forward and backward passes to compute gradients and perform a gradient descent weight update. |
| 03 | [*Linear Regression in PyTorch*](./lab-exercise-03.ipynb) | *Linear Regression in PyTorch* | Trains a two-layer linear regression model using PyTorch, SGD, and MSE loss on the Diabetes dataset. |
| 04 | [*PyTorch Tensor Basics*](./lab-exercise-04.ipynb) | *PyTorch Tensor Operations* | Covers core tensor operations, including seeding, array conversion, dtype casting, reshaping, indexing, and matrix multiplication. |
| 05 | [*Converting a CNN Architecture Diagram into PyTorch*](./lab-exercise-05.ipynb) | *CNN Architecture Implementation* | Translates a visual CNN diagram into a functional PyTorch nn.Module with spatial shape checks. |
| 06 | [*Image Classification Using Pre-trained Models*](./lab-exercise-06.ipynb) | *Model Inference on Custom Dataset* | Evaluates and compares five pre-trained torchvision models on a food dataset using cached feature extraction. |
